# Qwen2.5-0.5B 医疗问诊微调训练日志

## 项目概述

- **目标**: 微调 Qwen2.5-0.5B-Instruct 提升中文医疗问诊能力
- **目标设备**: 嵌入式设备 (2GB 内存)
- **量化方式**: Q4_K (~4.5 bits/weight) — 2GB设备黄金平衡点，体积约250MB，质量远优于IQ1_S
- **输出文件**: `/home/richard/qwen2.5-0.5b-q4_k_m.gguf`

## 已知限制

1. **CPU训练**: 仅使用1000条数据训练，全量数据(62万)训练效果会更好
2. **Q4_K量化**: Qwen2.5-0.5B的hidden_size=896不是256的倍数，Python版gguf库的K-quant无法直接使用。改用llama.cpp自带的C++量化工具 `llama-quantize`，其内部自动padding处理后量化，完美兼容。Q4_K是Q8_0和IQ1_S之间的最佳平衡点。
3. **评估数据有限**: 仅测试了男科3个样本，需要更全面的评估
